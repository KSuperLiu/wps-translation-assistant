快速开始

适用于支持 JavaScript 加载项的 Windows WPS 表格。识别与检查在本机处理；可采用表内已有的 AI 建议，也可自行配置在线 AI，主动为当前条目生成译文。

  1. 在安装网页点击安装或更新，完成后重新打开 WPS 表格。
  2. 打开任务表，点击顶部 翻译助手 → 打开助手。
  3. 确认任务语言，点击开始翻译 / 继续翻译，在目标语言的最终译文列填写。
  4. 完成后运行交付检查，用 WPS 保存或另存为交付文件。
两次保存要分清

在侧栏输入只是草稿；点击“写入并下一条”才进入工作簿。助手写入后，还需要用 WPS 保存到文件。

翻译人员怎么工作

1

接表：确认语言与填写范围

先保留需求方提供的原文件，使用任务副本翻译。“接表确认”会显示目标语言、翻译工作表数量，以及已填写、空译文等情况。多语言表需要选择本次任务语言。

看清“只填写……最终译文列”的提示。原文、旧译文、AI 和 Key 列各有用途，保持原结构；如果出现识别提示，先核实列关系再开始。

2

找条目：先补空译文，再处理问题

点击“开始翻译 / 继续翻译”或“下一条待处理”。助手优先寻找当前范围内未填写译文的条目，没有空译文后，再寻找已有译文但格式或 Key 检查有问题的条目。

展开“任务列表与查找”可按工作表和任务类型筛选，也可搜索 Key、原文或译文。下一条跳转遵循这些筛选条件；需要回到全任务时，选择“全部工作表”并清空搜索。

3

翻译：直接改表，或先写侧栏草稿

直接在表格填写：选中目标语言的最终译文单元格进行编辑，提交单元格后，助手会更新检查结果。侧栏随表格选区切换，点击“定位译文”可回到对应位置。

在侧栏编辑：在“最终译文草稿”里输入，核对后点击“写入并下一条”。“暂跳过”只切换条目，不会把当前条目记为完成。

当前原文与旧原文有变化时，会展示增删差异；“旧译文参考”可展开查看，也可以“以旧译文为底稿”。

4

用参考：核对表内 AI 建议后采用

有表内建议时，侧栏显示“表内 AI 建议”。点击采用 AI 并写入可直接填写当前译文；想先改内容，就点击先载入草稿，编辑后再写入。

覆盖已有译文或不同的未写入草稿前会要求确认。建议有格式问题时不能直接采用，需要先处理；格式通过后仍要核对含义、术语和上下文。

5

交付前：检查整个工作簿

点击顶部或侧栏的交付检查，重新检查当前目标语言在整个工作簿中的格式和 Key 问题，并查看识别提示、尚未写入的侧栏草稿。点击“去处理”可定位相关条目。

单条写入只核对、刷新当前工作表，避免每次遍历整个工作簿；交付检查仍会检查全工作簿。检查通过表示没有发现对应技术问题，翻译含义与术语仍需人工复核。

6

保存：将最终文件交回需求方

确保需要的草稿都已写入，再用 WPS文件 → 另存为保存新的 .xlsx 交付文件。保留工作表、表头、完整 Key 和原有格式。

“保存交付”区域可查看 WPS 报告的文件位置与保存状态。确认保存到正确文件后，再交回需求方。

当前功能一览

功能怎么用
识别翻译表与语言自动识别常见翻译表和多字段配置表；特殊表头可在“更多 → 识别设置”指定列。
原文变化与旧译参考查看新旧原文差异，展开旧译文，按需载入草稿。
表内 AI 建议直接采用并写入，或先载入草稿修改。
在线 AI 翻译配置 LiteLLM、统一网关或厂商官方 Key，为当前原文生成建议，核对后载入草稿。
问题检查与定位检查占位符、标签、换行标记及同一工作表内的重复完整 Key。
进度与查找查看已填写、空译文和问题数量；筛选、搜索后按当前范围继续处理。
复制完整 Key展开“条目信息”，点击完整 Key 右侧的“复制”。
写入与撤销写入前核对条目，避免改表后用旧位置覆盖；可撤销本会话最近一次助手写入。

在线 AI 配置

打开更多 → AI 设置，选择服务商或网关，直接复制并粘贴 Key，点击读取模型列表 / 测试连接，再选择或输入模型名称。地址、模型和 Key 都保存在当前用户的插件本机存储中，下次打开窗格自动恢复。Key 输入框以遮蔽方式显示；点击“清除保存的 Key”可移除已保存的 Key。切换服务或修改地址时也会清除 Key，需为新服务重新粘贴。

统一网关或厂商官方 Key

LiteLLM：填写管理员提供的 API 基础地址（例如 https://ai.example.com/v1）和虚拟 Key，使用网关开放的模型别名。网关管理上游厂商凭据，一个虚拟 Key 能使用哪些模型由管理员决定。

OpenRouter：选择后会预填地址，用对应 Key 读取模型。OpenAI、Anthropic、Gemini、DeepSeek、通义千问：使用各自服务的官方 Key；通义千问需选择 Key 对应的地域。其他服务可选择“其他 OpenAI 兼容服务”，填入完整基础地址。切换服务或修改地址会清空手填 Key，防止误发给另一个服务。

无需启动额外连接服务。选择 LiteLLM 后，填写网关地址，直接粘贴管理员提供的虚拟 Key，再读取并选择模型即可。

生成、核对、写入

选中条目，展开在线 AI 翻译，点击生成当前条目译文。仅发送当前原文与目标语言，不发送工作簿文件、路径、条目 Key、旧译文或草稿。结果显示格式问题，点击载入草稿后可编辑，再按原有流程写入并保存。切换条目、改变原文或编辑草稿会使旧建议失效；生成可取消，不自动重试。

连接与费用

请求发送到你配置的服务，费用和数据处理规则由该服务决定。直连模式需服务允许 WPS 窗格的跨域（CORS）访问；SDK 无法绕过跨域限制。模型列表接口不可用时，可以向管理员确认模型别名后手填。Key 不保存在工作簿、插件包或网站中。

检查规则与设置

占位符与富文本标签

例如 {0}、{name}、%s、%2$s 以及 TMP 富文本标签，需要保留对应片段和出现次数；标签还会检查闭合顺序。看到问题时，对照当前原文核实后修改。

换行标记 \n

在更多 → 检查设置 → 检查 \n 换行标记中切换，默认开启。这里的 \n 是反斜杠加字母 n，不是单元格里的实际换行。

  • 开启：检查译文比原文多了或少了多少个 \n。
  • 关闭：忽略 \n 的数量差异；其他占位符、标签和 Key 检查继续生效。

开关会记住本机选择。切换后先显示状态，再分批更新检查结果；存储不可用时会提示仅在本次窗格会话生效。

空译文与格式问题分别统计

允许原文或译文为空，空译文本身不会阻止交付检查通过，但仍会显示在翻译进度中。是否需要全部填写，应以本次翻译任务要求为准。“已填写”表示单元格有内容，不代表已人工审校。

更多操作

批量填充 AI 建议

在“更多 → 批量填充 AI 建议”中使用。只填充当前任务列表筛选范围内的空白译文，并要求确认；有未写入草稿时需先处理草稿。批量填充后仍需逐条复核内容。

撤销最近一次助手写入

在“更多”中点击“撤销最近一次助手写入”。撤销仅保留本次窗格会话中、当前工作簿最近一次成功写入；若写入后又人工修改了单元格，助手不会覆盖后来的修改。关闭窗格或重启 WPS 后不保证还能撤销。

特殊表头怎么设置

展开“更多 → 识别设置 · 特殊表头”，选择工作表，指定表头行、首条数据行、目标语言、字段名，以及 Key、原文、最终译文列。按需要指定旧原文、旧译文和 AI 列，再保存映射。

同一结构可添加多个字段或语种，配置保存在本机供同结构任务复用。如果不确定列的用途，先向需求方确认；点击“清除本结构的配置，恢复自动识别”可撤回该配置。

检查更新与安装更新

插件“更多”中显示当前版本，并提供“检查更新”。有新版时打开安装网站更新；更新前保存工作，按网站提示正常退出 WPS，完成后重新打开。

常见问题

草稿切换条目后还在吗？

本次窗格会话内会保留。关闭或重载窗格、重启 WPS 后会丢失，所以结束工作前请写入需要保留的草稿，再用 WPS 保存。

为什么不能写入？

先看草稿下方和面板顶部的问题提示。常见原因有格式检查未通过、当前表完整 Key 重复、内容或位置已变化，以及目标单元格是公式、合并格或受保护的单元格。改表后需要重新核对，不能继续用旧位置写入。

下一条怎么一直在某张表或某类条目里？

查看“任务列表与查找”中的工作表、任务类型和搜索条件。跳转只在当前筛选范围内进行，先空译文，后校验问题。选择“全部工作表”、合适的任务类型，并清空搜索即可扩大范围。

为什么有时识别很多工作表？

首次打开、手动重新识别和交付检查需要确认全工作簿。v1.3.12 起，单条草稿写入和单条 AI 采用只核对、刷新当前工作表。大量增删行列或调整结构后，可以手动重新识别。

安装后没有“翻译助手”选项卡怎么办？

先保存工作，正常关闭全部 WPS 表格窗口，再重新打开。仍未出现时回到安装网页重新检测，确认 WPS 版本支持 JavaScript 加载项。

能直接在 Microsoft Excel 中用吗？

当前插件支持 Windows WPS 表格。任务文件可以使用 .xlsx 格式，但插件本身需要在 WPS 中打开。
