检测到此前 EXE 安装的版本。请在 Windows“设置 → 应用”中卸载“WPS 翻译助手”，然后回到此页重新连接并安装。以后都可以在这里更新，避免两种管理方式冲突。

连接失败或没有看到插件？

请使用安装了 WPS 的 Windows 电脑，确认该 WPS 版本支持 JavaScript 加载项。若浏览器或企业策略阻止本机连接，请按组织规定联系管理员；此网页不会修改安全设置。
