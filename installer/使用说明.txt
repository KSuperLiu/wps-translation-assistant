WPS 翻译助手 {{VERSION}} · Windows 离线安装包

一、使用条件
Windows 10 / 11，以及支持 JavaScript 加载项的 Windows WPS 表格。
使用 Windows 自带的 .NET Framework；不需要安装 Node.js、npm、开发工具或另行部署网站。
全部插件资源内置在 EXE 中，安装和当前功能运行均不需要访问发布网站，没有常驻本地服务器。
本版在本机处理表格，不调用 AI 翻译服务；“采用 AI 建议”使用表格里已有的 AI 列。

二、首次安装
1. 保存工作，正常关闭全部 WPS 文档窗口。安装器不会强行结束 WPS。
2. 双击“WPS翻译助手-{{VERSION}}-离线安装.exe”。不必以管理员身份运行。
3. 点击“安装翻译助手”。如果已有同名开发版，点击“升级 / 切换为离线版”。
4. 提示安装完成后，重新打开 WPS 表格及翻译工作簿。
5. 在顶部“翻译助手”选项卡点击“打开助手”。
安装仅对当前 Windows 用户生效；换一个 Windows 账户需要在该账户下安装。
安装包可以从任意普通目录运行；安装后可以删除下载的安装包，不影响插件使用。

三、以后怎么更新
开发者发来新版 EXE 后，保存并关闭 WPS，双击新版 EXE，点击升级即可。
不需要先卸载；不会重复添加一个“翻译助手”选项卡。
同版本安装包支持修复；旧版本安装包不会覆盖更高版本。
安装器仅更新本翻译助手的注册项，保留其他 WPS 插件配置。
原配置和旧文件会先备份；失败时尝试回滚，并报告恢复结果。

四、如何卸载
任选一种入口：
  - Windows“设置 → 应用”中找到“WPS 翻译助手”，选择卸载；
  - 开始菜单找到“WPS 翻译助手 → 卸载 WPS 翻译助手”；
  - 再次运行本安装包，点击“卸载插件”。
保存并关闭 WPS 后，在管理窗口点击“卸载插件”并确认。
重开 WPS 后选项卡消失。安装器删除自身插件资源、注册项、管理程序和快捷方式，
保留备份及不属于安装清单的用户文件，不清理 WPS 的浏览器缓存，不修改翻译工作簿。

五、设置与文件位置
插件资源：%APPDATA%\kingsoft\wps\jsaddons\WpsTranslationAssistant_1.0.0
管理程序：%LOCALAPPDATA%\Programs\WpsTranslationAssistant
备份和失败日志：%LOCALAPPDATA%\WpsTranslationAssistantData
可在安装/管理窗口点击“打开设置与备份目录”。
目录中的 1.0.0 是固定加载容器版本，实际产品版本以安装窗口/Windows 应用列表为准。
离线版本之间保持相同加载地址；识别设置仍由 WPS 本地浏览器存储保存。
从 localhost 开发版或旧网站版首次迁移时，原浏览器地址下的识别设置不保证自动迁移，
必要时重新配置一次。清理 WPS 缓存、系统清理或企业策略仍可能影响这些设置。

六、常见问题
安装时提示 WPS 正在运行：保存并正常退出 WPS 文档窗口后重试。
没有“翻译助手”选项卡：确认安装完成后已退出并重新打开 WPS；检查该版本支持 JavaScript 加载项。
企业策略禁用加载项、脚本快捷方式或执行程序时，请联系 IT 管理员处理。
当前安装包未进行数字签名；需要可信签名的企业环境应由开发者/IT 签名后分发。
EXE 旁的 .sha256 文件用于核对文件是否一致，不能替代发布者数字签名。
采用 AI 建议会写入当前工作簿，请在任务副本上编辑，并使用 WPS 保存/另存。

本包仅支持 Windows WPS 表格，不支持 Microsoft Excel、Mac 或移动版 WPS。
